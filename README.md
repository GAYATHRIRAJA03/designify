# Designify – Creative Design Agency

Designify is a modern and responsive creative design agency portfolio website built with Next.js and Bootstrap.

## 🌐 Live Demo

https://designify-liard.vercel.app/

## 📌 About the Project

Designify is a professional portfolio website designed for a creative digital agency.

The website showcases the agency's services, portfolio projects, contact information, and responsive navigation.

## ✨ Features

- Responsive navigation bar
- Creative hero section
- Services section
- Portfolio showcase
- Contact form with validation
- Success message after form submission
- Responsive design for mobile, tablet and desktop
- Modern animations and hover effects
- Footer with contact information
- Vercel deployment

## 🛠️ Technologies Used

- Next.js
- React.js
- JavaScript
- HTML
- CSS
- Bootstrap
- Git
- GitHub
- Vercel
